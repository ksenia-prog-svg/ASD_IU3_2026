# Анализ асимптотической сложности: Задача 3

## Временная сложность
**Оценка:** `Θ(n)`
**Обоснование:**
1. Для точного подсчёта необходимо проверить каждый элемент массива ровно один раз.
2. Ранний выход невозможен: даже если найдено несколько вхождений, неизвестно, есть ли ещё дальше.
3. На каждой итерации: одно сравнение и одна операция инкремента счётчика (`O(1)`).
4. Итог: строго линейная зависимость `O(n)`.

## Пространственная сложность
**Оценка:** `O(1)`
**Обоснование:** Единственная дополнительная переменная — целочисленный счётчик `count`. Память не зависит от `n`.
