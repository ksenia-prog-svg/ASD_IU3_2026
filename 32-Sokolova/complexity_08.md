# Анализ асимптотической сложности: Задача 8

## Временная сложность
**Оценка:** `O(n)`
**Обоснование:**
1. Первый проход: подсчёт количества положительных и отрицательных элементов → `n` проверок знака.
2. Второй проход: распределение элементов по заранее выделенным массивам → `n` операций присваивания и инкремента указателей.
3. Нули пропускаются за `O(1)` на элемент.
4. Итог: `2n` операций → `O(n)`.

## Пространственная сложность
**Оценка:** `O(n)`
**Обоснование:**
1. Создаются два массива суммарной длины `p + neg ≤ n`.
2. Память выделяется однократно точного размера (без ресайзов), что гарантирует `O(n)` без скрытых констант.
3. Дополнительная память сверх вывода: 4 целочисленных счётчика → `O(1)`.
