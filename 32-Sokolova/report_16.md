# Отчёт: ЗаTask 16 — Сортировка по модулю
## Идея решения
Кастомный компаратор: первичный ключ — `Math.abs(x)`, вторичный — само значение `x`. Это гарантирует, что при равном модуле отрицательное число (меньшее по значению) окажется левее положительного.
## Выбор структуры данных
`Integer[]` необходим для передачи в `Comparator`. Примитивный массив не поддерживает кастомные компараторы без боксинга.
## Асимптотика
Время: `O(n log n)`, Память: `O(n)`. Детальный расчёт в `complexity_16.md`.
## Тестирование
- Пары `{-x, x}`: проверка приоритета отрицательных чисел.
- Нули: проверка корректности модуля `0`.
- Только положительные: проверка деградации к обычной сортировке.
