# Анализ асимптотической сложности: Задача 17

## Временная сложность
**Оценка:** `O(n log n)`
**Обоснование:**
1. Создание массива индексов: `O(n)`.
2. Сортировка индексов компаратором: `O(n log n)` сравнений.
3. Вычисление суммы цифр: для 32-bit `int` максимум 10 цифр → `O(1)` на элемент. В худшем случае `O(n * D)`, где `D=10` → константа.
4. Формирование результата: `O(n)`.
5. Итог: доминирует сортировка → `O(n log n)`.

## Пространственная сложность
**Оценка:** `O(n)`
**Обоснование:**
1. Массив индексов `Integer[]` → `O(n)`.
2. Результирующий массив `int[]` → `O(n)`.
3. Дополнительная память: константные переменные цикла. Итого `O(n)`.
