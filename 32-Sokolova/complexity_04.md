# Анализ асимптотической сложности: Задача 4

## Временная сложность
**Оценка:** `O(n)`
**Обоснование:**
1. Алгоритм использует два последовательных прохода:
   - Первый проход: подсчёт количества вхождений `k` → `n` операций.
   - Второй проход: заполнение результирующего массива → `n` операций.
2. Суммарно: `2n` операций сравнения и присваивания. Константный множитель опускается → `O(n)`.
3. Альтернатива с `ArrayList` потребовала бы амортизированного `O(n)` из-за возможных ресайзов внутреннего массива, поэтому выбран детерминированный двухпроходный подход.

## Пространственная сложность
**Оценка:** `O(k)`, где `k` — количество вхождений (`0 ≤ k ≤ n`)
**Обоснование:**
1. Выделяется массив ровно размера `k`.
2. В худшем случае (`k = n`, все элементы равны `x`) → `O(n)`.
3. В лучшем случае (`k = 0`) → `O(1)` (пустой массив).
4. Дополнительная память сверх вывода: `O(1)` (переменные `count`, `pos`).
