# Анализ асимптотической сложности: Задача 14

## Временная сложность
**Оценка:** `O(n²)` в худшем и среднем случае, `O(n)` в лучшем.
**Обоснование:**
1. На шаге `i` элемент `key = arr[i]` сдвигается влево, пока не найдёт своё место в отсортированном префиксе `arr[0...i-1]`.
2. Худший случай (массив отсортирован по возрастанию): каждый элемент сдвигается на `i` позиций. Сумма сдвигов: `Σ i = n(n-1)/2` → `O(n²)`.
3. Лучший случай (уже по невозрастанию): условие `arr[j] < key` ложно с первой проверки. Выполняется `n-1` сравнений → `O(n)`.
4. Асимптотическая оценка алгоритма указывается по худшему случаю: `O(n²)`.

## Пространственная сложность
**Оценка:** `O(1)`
**Обоснование:**
1. In-place сортировка. Сдвиги выполняются внутри массива.
2. Переменные `key`, `j`, `i` занимают константную память.
