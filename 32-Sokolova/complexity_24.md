# Анализ асимптотической сложности: Задача 24

## Временная сложность
**Оценка:** `O(n + E log E + O log O)`, где `E` — кол-во чётных, `O` — кол-во нечётных (`E+O=n`). В худшем случае `O(n log n)`.
**Обоснование:**
1. Разделение на два списка: `O(n)`.
2. Сортировка чётных: `O(E log E)`.
3. Сортировка нечётных: `O(O log O)`.
4. Слияние в результат: `O(n)`.
5. Итог: `O(n log n)` при равномерном распределении.

## Пространственная сложность
**Оценка:** `O(n)`
**Обоснование:**
1. Два `ArrayList` для хранения подмножеств → `O(n)` суммарно.
2. Результирующий массив → `O(n)`.
3. Итого дополнительная память: `O(n)`.
