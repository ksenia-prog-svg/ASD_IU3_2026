# Анализ асимптотической сложности: Задача 22

## Временная сложность
**Оценка:** `O(n + U log U)`, где `U` — количество уникальных элементов (`U ≤ n`). В худшем случае `O(n log n)`.
**Обоснование:**
1. Подсчёт частот через `HashMap`: `O(n)` (амортизированное `O(1)` на вставку).
2. Сортировка ключей (уникальных значений): `O(U log U)` сравнений.
3. Формирование результата: проход по отсортированным ключам и заполнение массива → `O(n)`.
4. Итог: `O(n + U log U)`. При `U ~ n` → `O(n log n)`.

## Пространственная сложность
**Оценка:** `O(n)`
**Обоснование:**
1. `HashMap` хранит до `n` пар → `O(n)`.
2. `List` уникальных ключей → `O(U) ≤ O(n)`.
3. Результирующий массив → `O(n)`.
4. Итоговая дополнительная память: `O(n)`.
