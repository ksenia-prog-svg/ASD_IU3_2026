# Анализ асимптотической сложности: Задача 11

## Временная сложность
**Оценка:** `O(n)`
**Обоснование:**
1. Первый проход: вычисление суммы → `n` операций. Деление на `n` для получения среднего → `O(1)`. Используется `double` для точности сравнения.
2. Второй проход: вычисление `Math.abs(arr[i] - avg)` и сравнение с текущим минимумом разницы → `n` операций.
3. При равенстве разниц условие `diff < minDiff` строгое, поэтому сохраняется первый найденный элемент (соответствует требованию "первый по индексу").
4. Итог: `2n` операций → `O(n)`.

## Пространственная сложность
**Оценка:** `O(1)`
**Обоснование:** Переменные `sum` (long), `avg` (double), `best` (int), `minDiff` (double). Фиксированный объём памяти.
