# Отчёт: Задача 8 — Фильтрация по знаку
## Идея решения
Двухпроходная фильтрация. Первый проход считает размеры, второй заполняет массивы. Нули игнорируются. Порядок элементов сохраняется.
## Выбор структуры данных
Два массива `int[]` для результата. Точное выделение памяти устраняет overhead динамических списков.
## Асимптотика
Время: `O(n)`, Память: `O(n)`. Детальный расчёт в `complexity_08.md`.
## Тестирование
- Смешанные знаки и нули: проверка разделения и сохранения порядка.
- Только нули: проверка возврата двух пустых массивов.
