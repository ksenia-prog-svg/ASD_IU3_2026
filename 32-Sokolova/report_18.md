# Отчёт: Задача 18 — Сортировка только чётных
## Идея решения
Извлечение чётных элементов в отдельный список, их сортировка, и обратная запись на позиции чётных элементов в исходном массиве. Нечётные остаются нетронутыми.
## Выбор структуры данных
`ArrayList` для динамического сбора чётных чисел без предварительного подсчёта. Примитивный массив для финального результата.
## Асимптотика
Время: `O(n log n)`, Память: `O(n)`. Детальный расчёт в `complexity_18.md`.
## Тестирование
- Чередование чётных/нечётных: проверка сохранения позиций нечётных.
- Отсутствие чётных: проверка возврата исходного массива.
- Все чётные: проверка полной сортировки.
