# Анализ асимптотической сложности: Задача 2

## Временная сложность
**Оценка:** `O(n)` в худшем и среднем случае, `O(1)` в лучшем.
**Обоснование:**
1. Используется линейный поиск с ранним выходом (`return i`).
2. Лучший случай: элемент находится на индексе 0 → 1 сравнение → `O(1)`.
3. Худший случай: элемент отсутствует или находится на последнем индексе → выполняются все `n` итераций → `O(n)`.
4. Средний случай (равномерное распределение): `(n+1)/2` сравнений → `O(n)`.
5. Асимптотическая оценка алгоритма указывается по худшему случаю: `O(n)`.

## Пространственная сложность
**Оценка:** `O(1)`
**Обоснование:** Используются только локальные переменные цикла и параметр `x`. Динамических структур не создаётся.
