# Отчёт: Задача 7 — Второй максимум
## Идея решения
Одновременное отслеживание двух максимумов. При обнаружении нового лидера старый становится вторым. Условие гарантирует различность элементов.
## Выбор структуры данных
Массив `int[]`. Две переменные `max1`, `max2`.
## Асимптотика
Время: `O(n)`, Память: `O(1)`. Детальный расчёт в `complexity_07.md`.
## Тестирование
- Стандартный массив: проверка логики обновления.
- Два элемента: проверка минимального размера.
- Один элемент: проверка возврата `MIN_VALUE`.
