# Отчёт: Задача 11 — Ближайший к среднему
## Идея решения
Вычисление среднего как `double` для точности. Второй проход ищет минимум модуля разницы. Строгое неравенство `<` сохраняет первый элемент при равенстве разниц.
## Выбор структуры данных
Массив `int[]`. Переменные `double` для точных вычислений.
## Асимптотика
Время: `O(n)`, Память: `O(1)`. Детальный расчёт в `complexity_11.md`.
## Тестирование
- Стандартный случай: проверка ближайшего.
- Равные расстояния: проверка сохранения первого по индексу.
- Один элемент: проверка возврата самого себя.
