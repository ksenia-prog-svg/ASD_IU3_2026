# Отчёт: Задача 10 — Последний кратный k
## Идея решения
Полный проход с перезаписью индекса при каждом совпадении. Финальное значение переменной указывает на крайний правый элемент. Ранний выход невозможен.
## Выбор структуры данных
Массив `int[]`. Переменная `lastIdx`.
## Асимптотика
Время: `O(n)`, Память: `O(1)`. Детальный расчёт в `complexity_10.md`.
## Тестирование
- Несколько кратных: проверка возврата последнего индекса.
- Отсутствие: проверка `-1`.
- Кратный только в начале: проверка корректности.
