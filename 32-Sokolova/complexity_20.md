# Анализ асимптотической сложности: Задача 20

## Временная сложность
**Оценка:** `O(n + k)`, где `k = max - min + 1` (диапазон значений).
**Обоснование:**
1. Поиск min/max: `O(n)`.
2. Заполнение массива частот: `O(n)`.
3. Восстановление отсортированного массива: проход по `count[]` длины `k` + запись `n` элементов → `O(n + k)`.
4. Если `k = O(n)`, сложность линейная `O(n)`. В худшем случае (огромный разброс) доминирует `k`.

## Пространственная сложность
**Оценка:** `O(k)`
**Обоснование:**
1. Массив частот `count[]` имеет размер `k`.
2. Дополнительная память: скалярные переменные → `O(1)`.
3. Итого: `O(k)`. При плотном распределении данных эффективно.
