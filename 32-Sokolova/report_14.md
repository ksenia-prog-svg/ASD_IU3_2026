# Отчёт: Задача 14 — Сортировка вставками
## Идея решения
Построение отсортированного префикса слева направо. Каждый новый элемент «вставляется» на правильное место путём сдвига больших элементов вправо. Направление сравнения изменено для сортировки по невозрастанию.
## Выбор структуры данных
Массив `int[]`. Эффективные сдвиги блоков памяти реализуются за `O(1)` на элемент благодаря сплошному расположению в памяти.
## Асимптотика
Время: `O(n²)`, Память: `O(1)`. Детальный расчёт в `complexity_14.md`.
## Тестирование
- Обратный порядок: проверка худшего случая сдвигов.
- Дубликаты: проверка стабильности условия `<` (не нарушает порядок равных).
- Уже отсортированный по убыванию: проверка лучшего случая `O(n)`.
