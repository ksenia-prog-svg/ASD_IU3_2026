# Отчёт: Задача 23 — Проверка анаграммы массивов
## Идея решения
Два массива являются перестановками тогда и только тогда, когда их отсортированные версии идентичны. Алгоритм сортирует копии и сравнивает побайтово.
## Выбор структуры данных
`int[]` копии. Избегает модификации входных данных и позволяет использовать быстрый `Arrays.equals()` после сортировки.
## Асимптотика
Время: `O(n log n)`, Память: `O(n)`. Детальный расчёт в `complexity_23.md`.
## Тестирование
- Перестановка: проверка совпадения отсортированных версий.
- Разные элементы: проверка раннего несовпадения.
- Разные длины: проверка отсечения по размеру.
