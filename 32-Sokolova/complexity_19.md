# Анализ асимптотической сложности: Задача 19

## Временная сложность
**Оценка:** `Θ(n + m)`
**Обоснование:**
1. Два указателя `i`, `j` проходят по массивам `a` и `b` ровно один раз.
2. На каждом шаге выполняется одно сравнение и одно присваивание → `O(1)`.
3. Цикл выполняется `n + m` раз. Хвостовые элементы копируются за `O(1)` на элемент.
4. Итог: линейная зависимость от суммарного размера → `O(n + m)`.

## Пространственная сложность
**Оценка:** `O(n + m)`
**Обоснование:**
1. Выделяется результирующий массив фиксированного размера `n + m`.
2. Дополнительная память сверх вывода: три указателя → `O(1)`.
3. Итоговая дополнительная память: `O(n + m)` (необходима для хранения результата).
