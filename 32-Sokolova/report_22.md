# Отчёт: Задача 22 — Сортировка по частоте
## Идея решения
Агрегация частот в хеш-таблице, сортировка уникальных значений по убыванию частоты (и по возрастанию значения при равенстве), последующая развёртка в итоговый массив.
## Выбор структуры данных
`HashMap<Integer, Integer>` для агрегации за `O(1)`. `ArrayList` для сортировки ключей. Позволяет избежать O(n²) при наивном подсчёте.
## Асимптотика
Время: `O(n log n)`, Память: `O(n)`. Детальный расчёт в `complexity_22.md`.
## Тестирование
- Разные частоты: проверка приоритета частоты.
- Одинаковые частоты: проверка сортировки по значению.
- Один элемент: проверка граничного случая.
