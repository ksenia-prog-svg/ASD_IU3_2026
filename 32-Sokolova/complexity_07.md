# Анализ асимптотической сложности: Задача 7

## Временная сложность
**Оценка:** `O(n)`
**Обоснование:**
1. Один проход по массиву. На каждом элементе выполняется:
   - Сравнение `val > max1` → при истинности: два присваивания.
   - Иначе: сравнение `val > max2` → при истинности: одно присваивание.
2. Максимум 3 операции сравнения/присваивания на элемент → `O(1)` на итерацию.
3. Итог: `c·n` → `O(n)`.

## Пространственная сложность
**Оценка:** `O(1)`
**Обоснование:** Две вспомогательные переменные `max1`, `max2`. Условие гарантирует различность элементов, поэтому проверка `val != max1` не требуется, что упрощает логику без изменения сложности.
