# Отчёт: Задача 4 — Все индексы элемента
## Идея решения
Двухпроходный алгоритм. Первый проход считает количество вхождений `k`, второй заполняет массив точного размера. Избегает `ArrayList` и ресайзов.
## Выбор структуры данных
Массив `int[]` для результата. Выделение памяти сразу под `k` элементов гарантирует детерминированное время.
## Асимптотика
Время: `O(n)`, Память: `O(k) ≤ O(n)`. Детальный расчёт в `complexity_04.md`.
## Тестирование
- Несколько вхождений: проверка порядка и количества.
- Отсутствие: проверка пустого массива.
- Одно вхождение: проверка корректности индекса.
