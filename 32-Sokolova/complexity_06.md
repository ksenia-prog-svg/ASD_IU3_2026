# Анализ асимптотической сложности: Задача 6

## Временная сложность
**Оценка:** `O(n)`
**Обоснование:**
1. Первый проход: вычисление суммы всех элементов → `n` операций сложения.
2. Вычисление среднего: деление суммы на `n` → `O(1)`.
3. Второй проход: сравнение каждого элемента со средним → `n` операций сравнения.
4. Итог: `2n + O(1)` → `O(n)`.

## Пространственная сложность
**Оценка:** `O(1)`
**Обоснование:**
1. Переменные `sum` (тип `long` для защиты от переполнения), `avg` (тип `int`), `count` (тип `int`).
2. Память не масштабируется с размером входных данных.
3. Условие гарантирует, что среднее является целым числом, поэтому округление не требуется.
