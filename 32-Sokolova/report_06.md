# Отчёт: Задача 6 — Элементы больше среднего
## Идея решения
Два прохода: вычисление суммы → среднее → подсчёт элементов строго больше среднего. `long` для суммы защищает от переполнения.
## Выбор структуры данных
Массив `int[]`. Промежуточные переменные примитивных типов.
## Асимптотика
Время: `O(n)`, Память: `O(1)`. Детальный расчёт в `complexity_06.md`.
## Тестирование
- Элементы выше среднего: проверка подсчёта.
- Все равны: проверка возврата `0`.
- Отрицательные числа: проверка корректного целочисленного деления.
