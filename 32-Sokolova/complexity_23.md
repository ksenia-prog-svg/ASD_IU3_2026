# Анализ асимптотической сложности: Задача 23

## Временная сложность
**Оценка:** `O(n log n)`
**Обоснование:**
1. Проверка длин: `O(1)`.
2. Копирование двух массивов: `O(n)`.
3. Сортировка обоих массивов: `2 * O(n log n) = O(n log n)`.
4. Попэлементное сравнение: `O(n)`.
5. Итог: доминирует сортировка → `O(n log n)`.
*Альтернатива:* Подсчёт частот за `O(n)` возможен, но сортировка надёжнее при ограниченном диапазоне и проще в реализации без хеш-коллизий.

## Пространственная сложность
**Оценка:** `O(n)`
**Обоснование:**
1. Две копии массивов для сортировки → `O(n)`.
2. Временные переменные циклов → `O(1)`.
3. Итого: `O(n)`.
