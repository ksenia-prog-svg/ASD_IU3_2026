# Отчёт: Задача 20 — Сортировка подсчётом
## Идея решения
Не сравнительная сортировка. Подсчёт частот каждого значения в смещённом диапазоне `[min, max]`, затем последовательная выгрузка значений согласно частотам.
## Выбор структуры данных
`int[] count` для частот. Позволяет избежать сравнений и достичь линейного времени при ограниченном диапазоне.
## Асимптотика
Время: `O(n + k)`, Память: `O(k)`. Детальный расчёт в `complexity_20.md`.
## Тестирование
- Отрицательные числа: проверка корректного смещения индексов.
- Одинаковые элементы: проверка множественной выгрузки.
- Пустой массив: проверка граничного условия.
