# Отчёт: Задача 19 — Слияние двух отсортированных массивов
## Идея решения
Классический алгоритм слияния (merge step). Сравнение головных элементов двух массивов и помещение меньшего в результат. Гарантирует стабильность и оптимальную линейную сложность.
## Выбор структуры данных
Примитивные массивы `int[]`. Прямой доступ по индексам позволяет реализовать слияние без накладных расходов.
## Асимптотика
Время: `O(n + m)`, Память: `O(n + m)`. Детальный расчёт в `complexity_19.md`.
## Тестирование
- Пересекающиеся диапазоны: проверка корректного порядка.
- Один пустой массив: проверка граничного случая.
- Дубликаты: проверка стабильности (сохранение порядка равных).
