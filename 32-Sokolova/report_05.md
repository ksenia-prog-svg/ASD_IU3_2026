# Отчёт: Задача 5 — Сумма чётных позиций
## Идея решения
Цикл с шагом `2`. Суммирование только элементов с индексами `0, 2, 4...`. Использование `long` предотвращает переполнение при больших входных данных.
## Выбор структуры данных
Массив `int[]`. Аккумулятор `long`.
## Асимптотика
Время: `O(n)`, Память: `O(1)`. Детальный расчёт в `complexity_05.md`.
## Тестирование
- Нечётная длина: проверка последнего элемента.
- Один элемент: проверка граничного случая.
- Пустой массив: проверка возврата `0`.
