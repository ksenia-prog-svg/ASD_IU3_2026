# Анализ асимптотической сложности: Задача 9

## Временная сложность
**Оценка:** `O(n)` в худшем случае, `O(1)` в лучшем.
**Обоснование:**
1. Алгоритм сравнивает соседние элементы `arr[i]` и `arr[i-1]`.
2. При первом нарушении неубывания (`arr[i] < arr[i-1]`) происходит немедленный возврат `false` → лучший случай `O(1)`.
3. Если массив отсортирован или инверсия находится в конце, выполняется `n-1` сравнений → худший случай `O(n)`.
4. Асимптотическая оценка: `O(n)`.

## Пространственная сложность
**Оценка:** `O(1)`
**Обоснование:** Используется только индекс цикла `i`. Никаких дополнительных структур не создаётся.
