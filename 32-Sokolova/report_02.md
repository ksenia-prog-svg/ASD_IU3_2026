# Отчёт: Задача 2 — Индекс первого вхождения
## Идея решения
Линейный поиск с ранним выходом. Возврат индекса при первом совпадении минимизирует время работы в среднем случае.
## Выбор структуры данных
Массив `int[]`. Прямой доступ к элементам без итераторов.
## Асимптотика
Время: `O(n)`, Память: `O(1)`. Детальный расчёт в `complexity_02.md`.
## Тестирование
- Элемент в середине: проверка возврата правильного индекса.
- Элемент отсутствует: проверка возврата `-1`.
- Элемент в начале: проверка лучшего случая `O(1)`.
