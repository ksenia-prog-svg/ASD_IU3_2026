# Анализ асимптотической сложности: Задача 16

## Временная сложность
**Оценка:** `O(n log n)`
**Обоснование:**
1. Боксинг `int[]` → `Integer[]`: `O(n)` операций создания объектов.
2. Сортировка `Arrays.sort()` с компаратором: использует Timsort (гибрид MergeSort + InsertionSort). Гарантированная сложность `O(n log n)` сравнений.
3. Компаратор выполняет две операции: `Math.abs(x)` и прямое сравнение. Обе `O(1)`.
4. Итог: доминирует сортировка → `O(n log n)`.

## Пространственная сложность
**Оценка:** `O(n)`
**Обоснование:**
1. Боксинг создаёт `n` объектов `Integer` в куче → `O(n)`.
2. Timsort требует буфер для слияния размером до `n/2` → `O(n)`.
3. Дополнительная память сверх вывода: `O(n)`.
