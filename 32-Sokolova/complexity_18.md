# Анализ асимптотической сложности: Задача 18

## Временная сложность
**Оценка:** `O(n + E log E)`, где `E` — количество чётных элементов (`E ≤ n`). В худшем случае `O(n log n)`.
**Обоснование:**
1. Первый проход: фильтрация чётных → `O(n)`.
2. Сортировка чётных: `O(E log E)`.
3. Второй проход: запись обратно в массив → `O(n)`.
4. Итог: `O(n + E log E)`. При `E ~ n` → `O(n log n)`.

## Пространственная сложность
**Оценка:** `O(E)`
**Обоснование:**
1. `ArrayList<Integer>` для чётных элементов → `O(E)` памяти.
2. Исходный массив модифицируется in-place.
3. Дополнительная память: `O(E)`.
