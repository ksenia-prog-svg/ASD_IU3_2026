# Анализ асимптотической сложности: Задача 5

## Временная сложность
**Оценка:** `O(n/2) = O(n)`
**Обоснование:**
1. Цикл шагает с инкрементом `i += 2`, выполняя ровно `⌈n/2` итераций.
2. На каждой итерации: одна операция сложения и одно обращение к памяти.
3. Линейный рост числа операций относительно `n` сохраняется → `O(n)`.

## Пространственная сложность
**Оценка:** `O(1)`
**Обоснование:**
1. Используется одна переменная-аккумулятор `sum`.
2. Тип `long` выбран намеренно: при `n = 10^5` и значениях элементов до `2·10^9` сумма может превысить `Integer.MAX_VALUE`. `long` гарантирует отсутствие переполнения без изменения асимптотики.
